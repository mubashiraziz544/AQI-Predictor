# AQI Predictor

## Features

- Fetches live weather data using OpenWeather API
- Fetches live AQI data using AQICN API
- Feature Engineering Pipeline
- Historical Data Backfill
- Random Forest Model Training
- SHAP Explainability
- Flask Prediction API
- Streamlit Dashboard

## Tech Stack

- Python
- Pandas
- Scikit-learn
- Flask
- Streamlit
- SHAP
- OpenWeather API
- AQICN API
